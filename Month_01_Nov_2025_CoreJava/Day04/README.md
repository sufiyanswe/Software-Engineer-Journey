# Day 4 - Bank Account Manager

## Overview

This project is a simple console-based Bank Account Manager built using the Java concepts learned on Day 4. It demonstrates how to use loops, switch-case, conditional logic, and basic arithmetic operations to simulate real banking actions such as checking balance, depositing money, and withdrawing money.

## Features

* Check current account balance
* Deposit money (with validation)
* Withdraw money (prevents overdraft)
* Menu-driven program using a loop
* Switch-case for clean option handling
* User-friendly messages and formatted output

## Concepts Practiced

* `while` loop
* `switch` statements
* Conditional logic (`if`, `else if`, `else`)
* Arithmetic operations (`+=`, `-=`)
* User input handling with `Scanner`
* Program flow control

## How It Works

The program starts with a fixed balance and runs inside a loop that continues until the user chooses to exit. Each operation updates the balance accordingly and gives real-time feedback.

## Learning Outcome

By completing this project, I understand how loops and switch-case work together to create interactive console applications. I also strengthen my understanding of conditionals, input handling, and implementing real-world logic in Java.
