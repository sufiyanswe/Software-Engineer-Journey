# 🩺 Day 2 - Personal Health Calculator

### 📘 Project Overview

Day 2 focused on building a **Personal Health Calculator** using Java. The goal was to strengthen core programming concepts like input handling, validation, mathematical operations, and formatted console output.

This project collects user data such as **age, height, and weight**, then calculates:

* Body Mass Index (BMI)
* Ideal Weight Range
* Recommended Daily Water Intake

All results are displayed in a clean, structured format with color-coded categories for better visualization.

---

### 💡 Learning & Experience

This project was more than just about formulas — it was about **translating logic into meaningful output**. The key learning outcomes included:

* Understanding user input flow and data validation in Java.
* Applying mathematical reasoning through formulas.
* Using formatted printing (`printf`) for clean presentation.
* Adding ANSI colors for dynamic and interactive console feedback.

It was a great reminder that even simple data can be presented **professionally and impactfully** with structured design.

---

### 🚀 Key Takeaways

* Focus on clarity, not complexity.
* Small details (like validation & formatting) improve user experience.
* Good code reads like a story — structured, purposeful, and clean.
