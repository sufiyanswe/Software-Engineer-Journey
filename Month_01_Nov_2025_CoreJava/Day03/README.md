# 🏋️‍♂️ Day 3 - Fitness Tracker Program

## 📘 Overview

This Java program, **Fitness Tracker**, was created as part of my Day 3 learning journey. It uses arithmetic, comparison, logical, and ternary operators to analyze a user's daily fitness data. The program calculates progress toward step and calorie goals, provides motivational feedback, and demonstrates multiple Java operator concepts in a real-world scenario.

## 💡 Learning Objectives

* Understand and apply **Java operators** (arithmetic, comparison, logical, ternary, increment/decrement, and compound assignment).
* Learn to take **user input** using the `Scanner` class.
* Perform **calculations** and display **formatted output** using `printf`.
* Use **conditional logic** to produce dynamic and meaningful results.
* Practice **modular problem-solving** by breaking a larger problem into smaller logical sections.

## ⚙️ Features Implemented

* Takes user input for name, step goal, calories, and exercise data.
* Calculates:

    * Remaining steps and calories
    * Step completion percentage
    * Net calories and distance walked (in miles)
* Checks if daily goals are met and rates the day accordingly.
* Updates streak and rewards points system.
* Prints a well-formatted fitness report with meaningful feedback.

## 🧠 Concepts Practiced

* **Arithmetic Operators:** `+`, `-`, `*`, `/`, `%`
* **Comparison Operators:** `>`, `<`, `>=`, `<=`, `==`, `!=`
* **Logical Operators:** `&&`, `||`, `!`
* **Ternary Operator:** `condition ? valueIfTrue : valueIfFalse`
* **Increment/Decrement:** `++`, `--`
* **Compound Assignment:** `+=`, `-=`

## 🧩 Outcome

This program strengthened my understanding of how different operators work in Java and how they can be combined to create meaningful applications. It also helped me practice writing **structured code**, organizing logic clearly, and using **printf** for clean, professional console output.

## 🚀 Next Step

On Day 4, I plan to start learning about **conditional statements (if-else, switch)** and apply them in a new mini project to deepen logical reasoning skills.
